# ExpenseFlow

Budget and Expense Reimbursement Management System for university
societies and small organizations.

## Academic Project

- Student: Muhammad Nouman
- Roll Number: BSEF24A001
- Course: Web Technologies
- Deliverable 1: Static frontend pages

## Overview

ExpenseFlow is designed to help members submit and track expense
claims while treasurers review requests and monitor the organization's
budget.

## Pages

- Home: introduction, sample budget overview, and workflow.
- Login: login form and links to preview both role dashboards.
- Sign Up: member registration form with basic validation.
- Member Dashboard: sample personal claims and status summaries.
- Treasurer Dashboard: sample organization budget and pending claims.

## Technologies

- HTML5
- CSS3
- Bootstrap 5.3.8
- JavaScript for basic form checks and demo messages

## How to Run

1. Download or clone this repository.
2. Keep the project folder structure unchanged.
3. Open index.html in a web browser.
4. Keep an internet connection available to load Bootstrap from its CDN.
5. Open Login and use the demo links to preview either dashboard.

## Current Scope

This deliverable is a static frontend prototype.

- All expense records and budget figures are sample data.
- Login does not authenticate users.
- Signup does not create or save accounts.
- Review, expense submission, and budget controls show demo messages.
- No database or backend is connected.
- Approved claims do not indicate completed reimbursement payments.
